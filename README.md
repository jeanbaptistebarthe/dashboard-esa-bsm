# Dashboard Althéa / BSM — site

Ce dépôt contient uniquement **la page du dashboard** (le code) : `index.html`, `app.js`, `config.js`.

**Aucune donnée n'est stockée ici.** Les projets, statuts, notes et documents vivent dans le dépôt **privé** `dashboard-esa-bsm-data`, et la page n'y accède qu'avec un jeton d'accès personnel — sans jeton, elle n'affiche qu'un écran de connexion vide.

- Adresse du dashboard : `https://jeanbaptistebarthe.github.io/dashboard-esa-bsm/`
- Marche à suivre complète : voir le guide fourni avec ce dossier (installation, jetons d'accès, usage quotidien).

Pour modifier le dashboard plus tard : remplacer les fichiers ici via **Add file → Upload files** (le site se met à jour tout seul en 1 à 2 minutes).
