Dashboard Althéa / BSM

Un seul tableau de bord pour piloter tes projets — statut, avancement, priorité, documents.

Connecté à GitHub — sauvegarde en direct
💡 Comment ça marche : envoie tes documents et infos à Claude dans la conversation en précisant le projet concerné — Claude analyse, produit les livrables (synthèses, PPT, calculs…), les rattache ici comme documents, et met à jour statut / avancement / historique du projet automatiquement. Les sujets sont traités par priorité : Haute avant Moyenne avant Basse. Chaque changement — ici ou fait par Claude — est enregistré par un commit dans ton dépôt GitHub privé de données.
Persistance : les données (projets, statuts, avancement, documents, historique) sont stockées dans le fichier data.json de ton dépôt GitHub privé — chaque changement crée un commit. Les documents joints sont stockés comme fichiers dans ce même dépôt privé (20 Mo max par fichier). Rien n'est visible sans le token.
